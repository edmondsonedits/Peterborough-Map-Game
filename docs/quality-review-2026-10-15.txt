   with null revisions are detected; legacy drafts are explicitly unverified.
   Recover, export, discard, corrupt storage and post-save rebase are covered.

   obsolete September release token. New consequential tests run in Pages CI.

or Firefox. Mission-arrival coordinates and changed-publication data were
deliberate test fixtures; no full emergency response was physically driven.

or suitability for operational navigation. No performance improvement is claimed.

real entry policy. Live authentication/publication was not attempted. Draft
identity stores an exact normalized base snapshot and can use more local storage;
quota/error paths are tested and surfaced, but browser storage remains finite.

and authenticated publishing checks remain release verification limits.
