# Simulator asset catalogue

Open index.html for the catalogue and gallery.html for the interactive model viewer. Online candidates are distinguished from installed models. Display sizes in the gallery are normalized for inspection.

The selected Kenney City Kit Roads models and shared colour texture are CC0. Their original licence is retained at ../../city-explorer/assets/streetscape/kenney/License.txt, with source URLs and file hashes in manifest.json beside it. Attribution is optional. Original project models use original procedural geometry and vertex colours.

Two downloaded poles and a generated decorative wire span are currently placed near Station 1. Other installed models are available for further placement. These illustrative assets do not establish real utility locations or traffic rules.

The JSON and SQLite files contain asset metadata; candidate libraries are not blanket approval of individual downloads. CC0 does not clear third-party trademarks or other third-party rights.
