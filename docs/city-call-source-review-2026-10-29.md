# City call sources and review — 2026-10-29

This report records source acquisition and bounded independent review for the city-call expansion. Source checks below are measured input checks, not a claim that every published facility is open, every point is an entrance, or final all-city routes/browser tests passed. Per-city gameplay provenance and the final release audit remain separate.

## Reproduce the inputs

Portable implementations are in [`tools/call-sources/official`](../tools/call-sources/official/README.md) and [`tools/call-sources/osm`](../tools/call-sources/osm/README.md). Both accept explicit repository/cache paths. Install their requirements in a separate Python environment; no dependencies are vendored. From the checkout root:

```sh
python tools/call-sources/official/acquire_snapshot.py --repo-root . --output-dir .cache/call-sources/official
python tools/call-sources/official/normalize_lode.py --repo-root . --output-dir .cache/call-sources/official
python tools/call-sources/official/refine_bundles.py --repo-root . --output-dir .cache/call-sources/official
python tools/call-sources/official/validate_bundles.py --repo-root . --output-dir .cache/call-sources/official
python tools/call-sources/osm/acquire_osm.py --repo . --cache .cache/call-sources/osm --download
```

Official acquisition reuses only size/checksum-valid pinned bytes; `--offline` validates an existing cache without requests. It fails if a mutable upstream file changes. OSM acquisition downloads only with explicit `--download` and a missing cache; it never silently refreshes an existing PBF. Reproduce this snapshot with the hash below, since `ontario-latest.osm.pbf` is mutable. Raw PBF/ZIPs, large caches, indexes, binaries and dependency trees are excluded from these portable directories. The sole bundled raw API snapshot is the 14,570-byte Thunder Bay facilities API response. Neither pipeline writes production city data.

## Licence, coordinates and currentness

Statistics Canada facility datasets use the [Open Government Licence – Canada](https://open.canada.ca/open-government-licence-canada); Ontario school datasets use the [Open Government Licence – Ontario](https://www.ontario.ca/page/open-government-licence-ontario); the municipal snapshot uses the [Thunder Bay open-data licence](https://www.thunderbay.ca/city-hall/thunder-bay-open-data/). These permit commercial reuse subject to their attribution/other conditions. OSM data is © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), under [ODbL1.0](https://opendatacommons.org/licenses/odbl/1-0/), with its attribution and applicable database share-alike obligations. Operator/institution web pages corroborate names, civic addresses or stated status; their evidence URLs do not confer a bulk geometry licence.

Excluded inputs include Ontario GeoHub School Facility metadata restricted to professional/non-commercial use, direct Belleville GIS without an established commercial open licence, stale 2022 business rows, and address-only childcare rows lacking coordinates. No civic numbers or replacement facility points were invented.

ODEF 2024 WKT points and direct Ontario private-school coordinates use EPSG:4326. ODHF/ODSRF EPSG:3347 coordinates are transformed to EPSG:4326; Thunder Bay is an ArcGIS `outSR=4326` query from an EPSG:3160 layer. Representative points from polygons/multipoints remain explicitly marked. OSM source geometry, raw civic tags, object IDs/versions/timestamps, source URLs and snapshot attribution remain in provenance. Municipal polygon membership and locality labels do not establish emergency response districts; Scarborough is an overlapping former-municipality game scope. Barrie's OSM boundary warns that its northern edge needs updating.

**A source point is not a verified vehicle entrance.** It may identify a building interior, parcel, campus, park asset or approximate geocode; even a mapped building entrance can be pedestrian-only. The source pipelines do not establish legal vehicle entry, arrival side, a navigable approach, actual station first-due responsibility or real-time availability. Game builders derive/screen road connections, cross streets and modeled assignments separately; modeling is not official dispatch policy.

Publication/retrieval dates do not prove current operation. ODEF geometry is from 2024 even when its address matches the September 2026 school roster; ODCAF cultural rows collected in 2020 require current corroboration. The explicit flags in the official README distinguish unreviewed currentness, current-address/old-coordinate matches, representative geometry and same-address coordinate conflicts. Reviews can correct only supported names/categories or reject an association; they do not move a point to a newly reported address.
