# Interface refresh — 1.6.102

This release improves choosing, using and reviewing training activities without changing the approved geography, scoring, vehicle calibration or local-record formats.

## Included

- Shared self-hosted Source Sans 3 and static Barlow heading fonts, semantic navy/cyan colors, visible keyboard focus, reduced-motion styles and readable control targets. Original font licenses ship with the files.
- Launcher with visible activity descriptions, specific actions and accurate free-driving city capabilities. City/service exits return to the intended launcher control.
- Geo Practice and Timed Games navigation, replayable instructions, associated form labels, deliberate screen focus, bounded wrapper startup and Retry. Optional scoreboard initialization is document-owned and survives browser Back without overwriting the live handlers.
- Route Mapping retains default continuous tracing. The optional Choose streets interface offers native tap/keyboard buttons over the same connected legal graph. Road loading has a bounded deadline, owned cancellation and same-page retry. Route review names the shortest legal distance explicitly.
- Dispatch has learner-first Options with Advanced settings, readable current street/speed/gear, service exits and history focus containment. Opening blocking panels releases movement. Existing tutorial, input cancellation and Fire/EMS completion behavior remain authoritative.
- City Explorer has native mode commands, named dialogs with focus return, movement buttons, touch map pan plus native navigation buttons, readable HUDs and useful WebGL recovery. Quick travel preserves the previous map view. Existing scene and asset fallbacks remain intact.
- Local editor typography and controls are larger. The call list and export area no longer cover each other; small screens scroll the full sidebar. Draft/export/publication boundaries remain unchanged.
- Shared build-version owns the visible production marker; module guards, cached-client forwarders and city runtime protocol 1.6.17 remain separate. Existing training-use information lives in menu/help areas instead of floating over input controls. Provider attribution remains visible.

## Verification before release

- Full Node regression suite: 378 passed, zero failed/skipped.
- Additional City Explorer runtime and geometry commands: 16 passed. Road terrain validation covers 5,953 roads and 2,965,162 surface points.
- Independent review found and verified corrections to Geo BFCache restoration, quick-travel map state, overlay interception and editor overflow. Focused review run: 32 passed.
- All 38 inspected local stylesheet/font references across 12 active entrypoints resolve. Release normalization is idempotent; changed classic scripts and inline scripts parse.

## Evidence limits

Physical-phone simultaneous input, software-keyboard fit, novice usability and GPU-enabled 3D scene performance require device testing. Automated behavior tests do not establish full accessibility conformance. This release makes no FPS or field Core Web Vitals improvement claim; no rendering/terrain optimizations were made without a measured device bottleneck. Two shared fonts total 229,176 uncompressed file bytes; they use font-display swap and system fallbacks. New interface code and styles add a small separate static layer rather than a framework runtime.
