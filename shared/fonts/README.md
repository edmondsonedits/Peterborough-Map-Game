# Interface fonts

Original unmodified WOFF2 distributions, self-hosted for the training interface.

- Source Sans 3 upright variable font: https://github.com/adobe-fonts/source-sans/tree/release/WOFF2/VF — SIL Open Font License 1.1, retained in SourceSans3-OFL.txt.
- Barlow Semi Condensed Semibold static font: https://github.com/jpt/barlow/tree/main/fonts/woff2 — SIL Open Font License 1.1, retained in Barlow-OFL.txt.

The UI uses system fallbacks and font-display swap. The static Barlow face is used only for selected short headings; no experimental variable Barlow build is required.
